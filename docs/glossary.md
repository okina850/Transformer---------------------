## 環境・再現性

### venv（仮想環境）
プロジェクトごとに独立した Python パッケージ群を持つ仕組み。
プロジェクトAが `numpy 1.x`、Bが `2.x` を要求するといった衝突を避けられる。
深層学習では「このバージョン一式でしか動かない」ことが多いため、事実上必須の慣行。
本プロジェクトは `C:\Users\user\venvs\rational_activation` を使う。

### cuDNN の非決定性
NVIDIA の深層学習ライブラリ。畳み込みなどで実行ごとに違う高速アルゴリズムを
自動選択することがあり、同じ入力でも結果が微小にぶれる。
`torch.backends.cudnn.deterministic = True` で禁止できる（速度は落ちる）。

## Transformer / 言語モデル

### FFN（Feed-Forward Network）層
Transformer の各ブロックにある、Attention の後段の2層全結合ネットワーク。
`W2 · act(W1 · x)` という形で、`act` が活性化関数。本研究が差し替える対象はここ。
モデル全パラメータの約2/3を占めるため、ここの設計変更は影響が大きい。

### pre-activation（活性化前の値）
活性化関数に入る直前の値、上式でいう `W1 · x`。
本研究では「近似区間 [-6,6] が実際の値域をカバーしているか」を判断するために
この分布を実測する。Transformer では外れ値が大きく出ることが知られている。

### GELU / `gelu_new`
GELU は `x · Φ(x)`（Φ は標準正規分布の累積分布関数）で定義される活性化関数。
誤差関数 `erf` の評価が要るため、実装によっては `tanh` を使った近似式で代用する。
Hugging Face の GPT-2 は後者（`gelu_new` と呼ばれる tanh 版）を使っている。
**近似の目標関数は実際にモデルが使っている方に揃える必要がある**
（誤差版に合わせると差し替えた時点でずれが生じるため）。

### SwiGLU
`(W_a·x) ⊗ SiLU(W_b·x)` の形のゲート付き活性化。行列が1枚多いので、
単純に活性化だけ差し替えるとパラメータ数が不揃いになる。
比較時は `d_ff`（FFN の中間層幅）で調整して揃える必要がある。

### SiLU / Swish
`x · sigmoid(x)`。GELU と形が近い滑らかな活性化関数。SwiGLU の中で使われる。

## 評価

### perplexity（パープレキシティ、PPL）
言語モデルの主要な評価指標。交差エントロピー損失の指数 `exp(loss)` を取ったもの。
直感的には「次のトークンを予測するときに、実質何個の候補で迷っているか」。
**小さいほど良い。** 本研究の主指標。

### スライディングウィンドウ perplexity 評価
文脈長（例: 1024トークン）より長い文書の PPL を測る標準的な方法。
窓をずらしながら（stride 512 など）評価し、各位置のトークンが十分な文脈を
持った状態で予測されるようにする。stride を小さくすると精度は上がるが計算量が増える。

### forward hook
PyTorch で、順伝播の途中の値を横取りして記録する仕組み。
モデルのコードを書き換えずに中間層の出力を取り出せる。
本研究では pre-activation の分布測定に使う。

## 実験手続き

### seed（乱数シード）
乱数生成器の初期値。深層学習では初期化・データ順序・dropout などが乱数に依存するため、
1つの seed の結果だけでは優劣を主張できない（CLAUDE.md が最低3つを要求している理由）。
Phase 0 は学習を伴わず決定論的なので、代わりに
「非線形最小二乗の初期値を3通り振って同じ解に収束するか」を確認する形で趣旨を満たす。

### 差し替え実験（frozen swap）とその限界
学習済みモデルの活性化関数だけを別のものに置き換え、**学習し直さずに**
性能を測る手法。安価で、近似の質が出力にどう効くかを切り分けられる。

**ただし学習を伴う実験の結果は予測しない。** 本研究で実証した反例:
Phase 0 の条件 R1 は RAFT 論文と同一設定だが、差し替えでは perplexity が
基準の1361倍に悪化した。しかし RAFT は同じ設定で学習させて GELU を上回っている。
理由は (1) 係数が凍結されており学習で改善する余地を無視している、
(2) 学習済み重みは元の活性化に最適化済みなのでズレが純損害になる、
(3) 「学習中の勾配安定性」に関する主張は学習しない実験では原理的に検証できない。

### MLM（Masked Language Modeling）/ 自己回帰言語モデル
- **MLM**: 文中の一部トークンを隠して当てさせる学習方式。BERT 系（encoder-only）が使う。
  前後両方の文脈が見える。RAFT はこちら。
- **自己回帰（causal LM）**: 左から順に次のトークンを予測する方式。GPT 系（decoder-only）。
  未来のトークンは見えない。本研究の Phase 1 はこちら。

同じ「言語モデル」でも学習信号の性質が違うため、片方の結果がもう片方で
再現するとは限らない。これが本研究の追試の立脚点である。

### 学習率スケジュール / パラメータ群ごとの学習率
学習率を学習の進行に応じて変える手続き。典型的には
**warmup**（最初の数%で 0 から目標値まで上げる。初期の不安定を避けるため）の後、
線形やコサイン状に減衰させる。

PyTorch の optimizer は **パラメータ群（parameter group）ごとに別の学習率**を
設定できる。RAFT はこれを使い、モデル本体は `lr=7e-4`（線形減衰）、
有理活性化の係数だけ `lr=5e-3`（warmup 後は**定数**）としている。
約7倍の差があり、スケジュールの形も違う。**追試ではここを揃えないと、
再現しなかったときに設定差か本質かを区別できない。**

### outlier features（外れ値特徴）
学習済み Transformer の中間表現に現れる、極端に大きな値を持つ少数の次元。
本研究の T5 でも GPT-2 の pre-activation が最大 62.97 に達することを実測した
（分布の std は 0.92）。モデル規模が大きいほど顕著になることが知られており、
**小規模モデルでは育たない可能性がある**（Phase 1 のリスクとして §10 に記載）。
