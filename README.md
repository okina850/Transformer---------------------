# 学習可能有理活性化関数の decoder-only Transformer における追試

BERT 系（encoder-only）で有理活性化関数（PAU）が GELU を上回ると報告した先行研究
（RAFT, EACL 2023）を受け、同じ手法を decoder-only の GPT 系言語モデルに適用し、
結果が再現するかを検証した。13.8M パラメータの decoder-only Transformer を
TinyStories 上でスクラッチ学習し、6条件 × 3 seed = 18本を比較した
（詳細な実験設定は [docs/FULL_REPORT.md](docs/FULL_REPORT.md) を参照）。

## 何が分かったか

- **精度は改善しなかった。** 全6条件の最終 perplexity の広がりは合計 2.36% で、
  GELU ベースラインはどの有理活性化条件とも統計的に区別できなかった。
  RAFT が encoder-only で報告した「有理活性化 > GELU」は、
  decoder-only・この規模では再現しなかった。
- **有理活性化は、分母設計によらず、勾配ノルムを GELU の約2〜2.5倍に押し上げる。**
  平滑分母（提案側）と PAU 型（先行研究側）のどちらでも同じ倍率で増幅されており、
  この差は分母の設計ではなく有理活性化という構造そのものに由来する。
  先行研究はこの水準を報告しておらず、KAT が示唆のみに留めていた不安定性の
  実測値を与えるものになった。
- **pre-activation の分布は学習中に育つ、という事前の予測が的中した。**
  学習開始時点では活性化への入力は近似区間 [-3,3] に完全に収まっていたが、
  600ステップで早くも [-6,6] を超え、最終的には分布の裾がその境界まで達した。
  PAU / RAFT が前提とする近似区間の妥当性は、学習の進行とともに崩れていく。
- **RAFT と同一設定（分母・区間・学習率の比とスケジュール）を忠実に再現した上で、
  発散が観測された。** 3 seed 中 1 つが学習中に発散した。低頻度事象であり
  統計的な主張はできないが、「同一設定を再現しても安定して動くとは限らない」
  という事実の記録として残す。

## このプロセスで重視したこと

学習を回す前に判定基準（発散の定義、条件間の差の定義）を文書化し、結果を見てから
変更しない方針を取った。これは Phase 0（学習を伴わない事前解析）で自分の結論を
複数回訂正した反省に基づく。実際、その事前登録があったことで、後の分析で
「窓を揃えずに比較していた」という自分自身の測定ミスに気づき、訂正することができた。
分母設計の効果を測るための実験は、次数と裾の挙動が同時に変わらないよう
交絡を分離して設計した。詳しい訂正の記録・機構分析・実装検証は
FULL_REPORT に記載している。
